Zero friction from source to launch

ZeroLaunch is a high-performance static site generator built in Python. It focuses on minimal configuration, deterministic builds, and fast, reproducible output so you can build, preview, and deploy without unexpected complexity or third-party dependencies.

# Installing ZeroLaunch via pip
pip install zerolaunch

# Serving your site
zerolaunch s

How it works

ZeroLaunch follows a simple, deterministic pipeline so your site builds are reproducible and fast. The default flow runs without configuration, but exposes a typed configuration for power users.

Source-first

Write content and templates in your repo—ZeroLaunch reads from the source tree.

Deterministic build

Parallel tasks and aggressive caching ensure repeatable outputs.

Publish-ready

Outputs are simple static artifacts ready for any CDN or static host.

CLI quick reference

Common commands to build, preview, and inspect your site.

## Build the site
	python example/zerolaunch.py build

	## Preview output locally
	python -m http.server --directory docs 8000

	## Show cache stats
	python example/zerolaunch.py cache --status

FAQ

Do I need any external dependencies?

No, ZeroLaunch aims to run with the Python standard library; additional integrations are optional.

Which Python versions are supported?

ZeroLaunch targets Python 3.11+ for modern typing and performance features.

Can I extend the pipeline?

Yes, configuration is explicit and typed, allowing safe extension points for transforms and plugins.
